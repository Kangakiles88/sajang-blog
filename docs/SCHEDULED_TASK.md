# 예약 작업 지시문

Claude 데스크톱 앱의 예약 작업("사장님노트 초안 작성", 매일 저녁 7시 48분)이 실행할 때 받는 지시의 사본입니다. 실제 지시를 바꾸려면 앱의 예약 작업 설정에서 프롬프트를 고치세요.

---

사장님노트 블로그(소상공인 지원금·세금 정보 사이트)의 초안을 1개 작성하고, 작성한 내용을 2차 검증해 주세요.

프로젝트 폴더: 사용자 컴퓨터의 D:\sajang-blog
(이 실행은 클라우드에서 돌아갑니다. 폴더는 사용자 컴퓨터 연결 도구로 읽고 씁니다. 웹 조사는 WebSearch/WebFetch로 하고, WebFetch가 막힌 공식 사이트(중기부·소진공 등)는 사용자 컴퓨터의 데스크톱 앱 내장 브라우저로 여세요. 컴퓨터에 연결할 수 없으면 아무것도 쓰지 말고 그 사실만 보고하세요.)

**준비**
1. docs/WRITING_GUIDE.md를 끝까지 읽고 그 규칙을 그대로 따르세요. 특히 "파일 형식"의 factCheck(검증표)와 "2차 검증 절차"를 반드시 지켜야 합니다.
2. keywords/queue.md에서 "- [ ]" 상태인 첫 번째 글감을 고르세요. 없으면 "글감이 없습니다"라고 보고하세요.
3. content/drafts/에 초안이 5개 이상 쌓여 있으면 새로 쓰지 말고 보고하세요.

**1차: 작성**
4. 공식 출처(중기부, 소진공, 국세청·홈택스, 법령정보센터, 정책브리핑, 기업마당, 지자체)를 조사하세요. 언론 기사는 공식 원문을 찾는 단서로만 쓰고, 숫자의 근거는 공식 원문으로 삼으세요. WebFetch로 안 열리는 공식 페이지는 데스크톱 앱 내장 브라우저(Claude_Browser 도구)로 여세요(WRITING_GUIDE "공식 사이트가 안 열릴 때").
5. content/drafts/<파일이름>.md로 저장하고, 본문의 금액·비율·기한·인원마다 factCheck.items에 근거를 적으세요.

**2차: 검증 (쓴 내용을 믿지 말고 처음부터 다시)**
6. 각 source URL을 다시 열어 원문에서 숫자를 직접 찾고, 위치와 원문 표현을 evidence에 적으세요.
7. 같으면 일치, 다르면 본문을 고친 뒤 일치. 못 찾으면 내장 브라우저로 다시 열어 보고, 그래도 못 찾으면 본문에서 빼고 reviewNotes에 "뺀 내용"으로 적으세요([확인 필요]는 빼면 글이 성립하지 않을 때만).
8. 원문의 기준 연도와 공고 날짜를 확인하세요.
9. 검증표에 없는 숫자를 추가하고 factCheck.checkedAt에 오늘 날짜를 적으세요.

**마무리**
10. queue.md의 해당 줄을 [d]로 바꾸세요.
11. git commit/push 금지. src/content/posts/에 쓰기 금지. 한 번에 1개만. 파일 삭제 금지.
12. 글 제목, 검증 결과(일치/수정/확인불가 수), 뺀 내용, 사용한 공식 출처를 보고하세요.
