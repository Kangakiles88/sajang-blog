# 예약 작업 지시문

Claude 데스크톱 앱의 예약 작업("사장님노트 초안 작성")이 매번 실행할 때 받는 지시입니다. 지시를 바꾸고 싶으면 앱의 예약 작업 설정에서 프롬프트를 고치세요. 아래는 처음 설정한 내용의 사본입니다.

---

사장님노트 블로그의 초안을 1개 작성해 주세요.

프로젝트 폴더: 내 컴퓨터의 `D:\sajang-blog` (연결된 폴더)

1. 먼저 `docs/WRITING_GUIDE.md`를 끝까지 읽고 그대로 따르세요.
2. `keywords/queue.md`에서 `- [ ]` 상태인 첫 번째 글감을 고르세요. 대기 중인 글감이 없으면 아무것도 쓰지 말고 "글감이 없습니다"라고 보고하세요.
3. `content/drafts/`에 이미 `[d]` 상태의 초안이 5개 이상 쌓여 있으면 새로 쓰지 말고 "검토 대기 초안이 5개 이상입니다"라고 보고하세요.
4. 웹 검색으로 공식 출처(중기부, 소진공, 국세청, 법령정보센터, 정책브리핑, 지자체)를 조사하고, 숫자는 공식 출처에서 확인하세요. 확인 못 한 숫자는 `[확인 필요: ...]`로 표시하세요.
5. `content/drafts/<파일이름>.md`로 저장하고, `keywords/queue.md`의 해당 줄을 `[d]`로 바꾸세요.
6. git commit/push는 하지 마세요. `src/content/posts/`에는 쓰지 마세요.
7. 끝나면 쓴 글의 제목, 확인이 필요한 부분 요약, 사용한 출처 목록을 짧게 보고하세요.
