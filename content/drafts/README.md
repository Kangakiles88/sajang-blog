# 초안 폴더

예약 작업이 여기에 초안을 씁니다. 이 폴더의 글은 사이트에 올라가지 않습니다.

검토 순서:

1. `npm run drafts` 로 목록과 문제점을 확인합니다.
2. 초안 파일을 열어 `reviewNotes`와 `[확인 필요]` 표시를 보고, `sources`의 원문 링크와 숫자를 대조합니다.
3. 고칠 곳을 고치고 `[확인 필요]` 표시를 모두 지웁니다.
4. `npm run publish-draft -- <파일이름>` 으로 발행합니다.

마음에 안 드는 초안은 파일을 지우고, `keywords/queue.md`에서 해당 줄을 `[ ]`로 되돌리면 다음에 다시 씁니다.
